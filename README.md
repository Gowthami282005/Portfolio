# Gowthami M — Portfolio

A personal portfolio website — plain HTML/CSS, no build step, no subfolders (so GitHub's drag-and-drop upload always works).

## Files (all go in the repo root — no folders)

```
index.html
style.css
profile.jpg
Gowthami_M_Resume.pdf
```

## Publish with GitHub Pages

1. Go to your repository on GitHub.
2. Click **Add file → Upload files**.
3. Drag in **all four files at once** (`index.html`, `style.css`, `profile.jpg`, `Gowthami_M_Resume.pdf`) — since nothing needs to go in a subfolder, plain drag-and-drop works every time.
4. Click **Commit changes**.
5. Go to **Settings → Pages**, set Source to the `main` branch, root folder, and Save.
6. Your site goes live at:
   ```
   https://gowthami282005.github.io/Portfolio/
   ```
   Give it a minute, then hard-refresh (Ctrl+Shift+R / Cmd+Shift+R) to clear any cached version.

## Before you publish

- If your repo currently has an `assets` folder or old files from a previous upload, delete them first (click into the file on GitHub → the trash/delete icon) so there's no confusion between old and new versions.
- Your LinkedIn link is already wired up to your real profile.

## Updating content later

All the content lives in `index.html` — you can open it on GitHub (pencil/edit icon) and edit text directly in the browser, then commit.
